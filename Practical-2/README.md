🧠 Employee Attrition Prediction (Deep Learning)
📌 Overview

This project predicts whether an employee will leave the company using a Deep Learning binary classification model built with TensorFlow/Keras.

📂 Dataset

IBM HR Analytics Employee Attrition Dataset
🔗 https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

1470 records

45 features

Target: Attrition (Yes/No)

🛠️ Tech Stack

Python

Pandas & NumPy

Scikit-learn

TensorFlow / Keras

⚙️ Process

Label Encoding for categorical features

Train-Test Split (80:20)

Feature Scaling (StandardScaler)

Neural Network with ReLU & Sigmoid

📊 Results

✅ Best Test Accuracy: 88.44%

Evaluated using Accuracy, Precision, Recall, F1-score & Confusion Matrix
